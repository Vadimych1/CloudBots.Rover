# Как использовать алгоритм
1. Создайте виртуальное окружение: `python3 -m venv venv`. Перед этим убедитесь, что вы используете Python 3.9 и выше.
2. Активируйте виртуальное окружение (если вы не используете редакторы кода, например, VSCode или PyCharm): `source venv/bin/activate`.
3. Установите зависимости: `pip install -r requirements.txt`.
4. Запустите приложение: `python3 main.py`.

После запуска на компьютере запустится веб-сервер на порту 1025, WebSocket-сервер на порту 1026.
Чтобы подключиться к панели управления с другого компьютера, откройте консоль на роботе и введите: `ifconfig`. Найдите вашу сеть и запишите ip-адрес.
Перепишите ip-адрес в адресую строку браузера следующим образом: `xxx.xxx.xxx.xxx:1025`. После открытия страницы вы увидите интерфейс управления.
В поле ввода адреса WebSocket-сервера введите `ws://xxx.xxx.xxx.xxx:1026`, нажмите подключиться. Всё подключено.

# Исправление ошибок
При возникновении ошибок при запуске, убедитесь:
1. Что вы испольузете версию Python 3.9 и выше.
2. Вы используете поддерживаемую ОС (Linux) и архитектуру процессора (arm64, arm32). Если нет, *скомпилируйте программу под свой процессор* файлом 'libs/arduino_motor/compile.sh'.
3. Проверьте правильность установки зависимостей в файле 'requirements.txt'.

Также, убедитесь, что порты, используемые приложением, не заняты другими программами.
